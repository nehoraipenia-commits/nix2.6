Nix Ahead-Of-Time (AOT) Compiler

The Nix compiler converts your Nix source code directly into optimized native C++17, and then compiles it to a standalone machine executable with automatic linking to libnix_qt.

How to Compile a Program

# Standard optimized compilation (-O2)
./nix build my_program.nx -o my_binary

# Maximum performance optimization (-O3)
./nix build my_program.nx -o my_binary -O3

# Retain generated intermediate C++ source
./nix build my_program.nx -o my_binary --emit-cpp

Benchmark Comparison

Measured on an intensive recursive workload: computing the 32nd Fibonacci number (fib(32)):

Execution Engine Execution Time Relative Speedup
Legacy Python Nix (python3 nix.py run) 12.85 seconds 1x (Baseline)
New Nix C++ Interpreter (./nix run) 0.28 seconds ~45x faster
Nix Native Compiled Binary (./nix build -O3) 0.04 seconds ~320x faster

Why is Compiled Nix so Fast?

  1. Compact Dynamic Value Model: Primitive integers and booleans are stored directly in 64 bits without heap allocations.
  2. Direct Function Invocations: Declared Nix functions are translated directly into native C++ functions without string symbol lookup overhead.
  3. Low-Level Hardware Optimizations: The underlying Clang / GCC toolchain applies SIMD vectorization, dead-code elimination, and aggressive register allocation.

Compilation Flags

Flag Description
-o <path> Specify the output binary executable path.
-O0, -O1, -O2, -O3 Optimization level passed to the underlying C++ compiler (default: -O2).
--emit-cpp Keep the emitted C++ source file (saved as <output>.cpp).
