Math Library <math>

Provides standard arithmetic, trigonometry, and high-precision calculations.

using <math>

Constants

Constant Description
pi Pi constant (3.141592653589793).
e Euler's constant (2.718281828459045).
pi_str Exact 100-decimal-place Pi string.

Functions

Function Description Example
math_abs(x) Absolute value. math_abs(-42) -> 42
math_sqrt(x) Square root (x >= 0). math_sqrt(25) -> 5.0
math_pow(base, exp) Exponentiation x^y. math_pow(2, 8) -> 256.0
math_ceil(x) Rounds up to the nearest integer. math_ceil(4.2) -> 5
math_floor(x) Rounds down to the nearest integer. math_floor(4.9) -> 4
math_sin(rad) Sine in radians. math_sin(pi / 2) -> 1.0
math_cos(rad) Cosine in radians. math_cos(0) -> 1.0
math_tan(rad) Tangent in radians. math_tan(0) -> 0.0
math_log(x, [base]) Natural or custom-base logarithm. math_log(e) -> 1.0
math_factorial(n) Factorial of non-negative integer n!. math_factorial(5) -> 120
hp_mul(a, b) High-precision multiplication. hp_mul(3.5, 2.0) -> 7.0
hp_div(a, b) High-precision division. hp_div(10, 3) -> 3.3333333333...
