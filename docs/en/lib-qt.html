Qt6 GUI Framework <qt> (libnix_qt)

The native libnix_qt C++ library connects Nix directly with Qt6, allowing you to build reactive, modern desktop applications with full styling and callbacks.

using <qt>

Automatic Event Loop

Creating a window with qt_window displays it immediately. When your script finishes its top-level statements, the native Qt6 event loop starts automatically, keeping your window open and interactive without needing a while true loop!

Widget Creation

Function Description
qt_window(title, width, height) Creates and displays a main Qt6 window.
qt_label(parent, text) Creates a text label (QLabel).
qt_button(parent, text, [callback]) Creates a push button (QPushButton) with optional click handler.
qt_input(parent, [placeholder]) Creates a single-line input field (QLineEdit).
qt_textarea(parent, [text]) Creates a multi-line text editor (QTextEdit).
qt_checkbox(parent, text, [checked]) Creates a toggleable checkbox (QCheckBox).
qt_slider(parent, min, max, value) Creates a horizontal slider (QSlider).
qt_progressbar(parent, min, max, val) Creates a progress bar (QProgressBar).
qt_combobox(parent, [items]) Creates a drop-down selection box (QComboBox).
qt_listwidget(parent, [items]) Creates a list view (QListWidget).

Containers & Layouts

  • qt_vbox(parent): Vertical layout container.
  • qt_hbox(parent): Horizontal layout container.
  • qt_frame(parent): Decorative styled panel frame.
  • qt_groupbox(parent, title): Titled group box container.

Events & Properties

Function Description
qt_set_text(widget, text) / qt_get_text(widget) Sets or reads text content from a widget.
qt_set_value(widget, val) / qt_get_value(widget) Sets or reads numerical value (slider, progress bar).
qt_is_checked(cb) / qt_set_checked(cb, bool) Checks or sets checkbox state.
qt_set_style(widget, qss) Applies QSS / CSS styling rules.
qt_on_click(btn, callback_fct) Attaches a Nix function to a button click event.
qt_on_change(widget, callback_fct) Fires when widget value or text changes.
qt_timer(ms, callback_fct, [repeat]) Calls a function every X milliseconds.

Native Dialogs

  • qt_msgbox(title, message): Native information popup.
  • qt_confirm(title, question): Confirmation dialog (returns boolean).
  • qt_file_dialog([title], [filter]): File picker dialog.
  • qt_color_dialog([title]): Graphical color picker.

Complete Application Example

using <qt>

win = qt_window("Nix Qt6 App", 400, 300)
qt_set_style(win, "QWidget { background: #181825; color: white; font-size: 14px; } QPushButton { background: #89b4fa; color: #111; padding: 8px; border-radius: 4px; font-weight: bold; }")

lbl = qt_label(win, "Enter your name below:")
inp = qt_input(win, "Your name...")

fct on_click() {
    name = qt_get_text(inp)
    qt_set_text(lbl, "Welcome " + name + "!")
}

btn = qt_button(win, "Submit", on_click)
