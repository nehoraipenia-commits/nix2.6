Built-in Functions & Object Methods

Nix features built-in methods on strings, vectors, and dictionaries, along with the <builtins> module.

String Methods

Method Description
s.upper() / s.lower() Converts string to uppercase or lowercase.
s.strip() Removes surrounding whitespace.
s.split([sep]) Splits string into vector parts based on delimiter.
s.replace(old, new) Replaces occurrences of substring.
s.startswith(p) / s.endswith(p) Checks prefix or suffix match.
s.find(sub) Returns index of substring (-1 if not found).
s.isdigit() / s.isalpha() Character validation tests.

Vector (List) Methods

Method Description
v.append(item) Adds an item to the end of the vector.
v.pop([index]) Removes and returns item at index (last by default).
v.insert(index, item) Inserts item at index position.
v.reverse() Reverses vector order in-place.
v.sort([reverse]) Sorts elements in ascending (or descending if true) order.
v.clear() Empties all elements.

Dictionary Methods

Method Description
d.keys() / d.values() Returns list of keys or values.
d.get(key, [default]) Safely accesses key value without throwing an error if absent.
d.pop(key) Removes and returns key value.
d.clear() Empties all key-value entries.

Module <builtins>

using <builtins>

out("Length:", len([1, 2, 3]))
out("Max value:", max(10, 42, 5))
out("Sum:", sum([10, 20, 30]))
out("Range:", range(0, 5))
