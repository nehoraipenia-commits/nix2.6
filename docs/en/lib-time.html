Time Library <time>

Provides benchmark timers, execution sleep pauses, and date formatting.

using <time>

Functions

Function Description
time_now() Returns current high-resolution system timestamp (Unix epoch in seconds).
time_sleep(seconds) Suspends execution for seconds (accepts floating-point values like 0.25).
time_format([timestamp], [format]) Formats a timestamp into a readable date string (defaults to "%Y-%m-%d %H:%M:%S").

Benchmarking Example

using <time>

start = time_now()

# Task simulation
time_sleep(0.15)

elapsed = time_now() - start
out("Elapsed time:", elapsed, "seconds")
out("Current date:", time_format())
