Complete Nix Syntax Reference

Nix features clean curly-brace blocks { ... } combined with lightweight dynamic typing.

1. Variables & Data Types

# Integers & Floating-point numbers
age = 25
rate = 3.14159

# Booleans (lowercase: true / false)
active = true
blocked = false

# Strings
message = "Hello World"

# Vectors (lists)
numbers = [10, 20, 30]
numbers.append(40)
first = numbers[0]

# Dictionaries (key-value maps)
user = {
    "name": "Alice",
    "score": 100
}
user["score"] = 150

2. Input & Output: out() and cin()

# Print to console with out(...)
out("Welcome to", "Nix", 2026)

# Read from console with cin(...)
name = cin("Enter your name: ")
out("Nice to meet you", name)

3. Conditionals: if / else

score = 85

if score >= 90 {
    out("Excellent!")
} else if score >= 70 {
    out("Well done!")
} else {
    out("Keep practicing.")
}

4. Loops: while and for

Nix features a custom concise for loop syntax with the * operator to iterate from 0 to N-1:

# Custom for loop: 'for variable * limit'
for i * 5 {
    out("Loop index:", i)
}

# Standard while loop
counter = 0
while counter < 3 {
    out("Count:", counter)
    counter = counter + 1
}

5. Functions: fct

Functions are declared with fct:

fct add(a, b) {
    return a + b
}

result = add(12, 30)
out("Result:", result) # 42

6. Classes & Objects: class

Nix supports object orientation with methods and fields:

class Player {
    name = "Hero"
    hp = 100

    fct take_damage(amount) {
        hp = hp - amount
        out(name, "now has", hp, "HP")
    }
}

p = Player()
out("Player name:", p.name)
p.take_damage(20)

7. Importing Libraries: using <...>

using <math>
using <time>
using <qt>
