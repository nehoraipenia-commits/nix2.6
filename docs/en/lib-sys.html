System & Files <sys>

Provides filesystem manipulation, operating system inspection, and shell process execution.

using <sys>

File Operations

Function Description
file_write(path, content) Writes string content to a file (overwrites if existing). Returns true.
file_read(path) Reads and returns entire file content as a string.
file_exists(path) Checks if a file or directory exists. Returns a boolean.
file_delete(path) Deletes a file from the disk.

OS & Process Operations

Function Description
sys_args() Returns the list of command-line arguments passed to the script.
sys_execute(command) Runs a shell command and returns a dictionary with stdout, stderr, and code.
os_name() Returns operating system family (e.g. "posix" or "nt").
os_listdir([path]) Returns a list of filenames in the specified directory path (defaults to ".").

Example

using <sys>

file_write("sample.txt", "Testing Nix Native C++ filesystem")

if file_exists("sample.txt") {
    data = file_read("sample.txt")
    out("Read data:", data)
    file_delete("sample.txt")
}

cmd = sys_execute("uname -m")
out("Machine architecture:", cmd["stdout"].strip())
