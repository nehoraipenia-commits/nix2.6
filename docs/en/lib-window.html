2D Canvas Module <window>

The <window> module (also aliased as <mac_window> for backward compatibility) provides a real-time 2D drawing canvas powered by Qt6 hardware double-buffering.

using <window>

Canvas Functions

Function Description
window_open(title, w, h) Opens a canvas window with width w and height h. Returns the window handle ID.
window_is_open(win) Returns true if the window is currently open, false if closed by the user.
window_poll_events(win) Dequeues the next pending keyboard or mouse event as a dict: {"type", "key", "x", "y"}.
window_clear(win, r, g, b) Clears the canvas background using RGB values (0 to 255).
window_draw_rect(win, x, y, w, h, r, g, b, [filled]) Draws an outline or filled rectangle.
window_draw_circle(win, cx, cy, radius, r, g, b, [filled]) Draws an antialiased outline or filled circle.
window_draw_line(win, x1, y1, x2, y2, r, g, b, [thickness]) Draws a straight line between two points.
window_draw_text(win, text, x, y, r, g, b, [font_size]) Renders text at (x, y) with a clean system font.
window_present(win) Flushes drawing commands and presents the back-buffer to the screen.
window_close(win) Programmatically closes the canvas window.

Static Drawing Example (No while loop required)

Nix automatically enters the Qt event loop if an unclosed window exists, keeping your window open without requiring an explicit busy loop:

using <window>

win = window_open("Nix 2D Canvas Art", 500, 400)

window_clear(win, 25, 25, 35)
window_draw_rect(win, 50, 50, 150, 100, 255, 100, 120, true)
window_draw_circle(win, 350, 200, 50, 100, 200, 255, true)
window_draw_text(win, "Nix C++ Native Canvas", 150, 25, 255, 255, 255, 18)
window_present(win)

# The window stays open automatically until you close it!

Interactive Game Loop Example

using <window>
using <time>

win = window_open("Bouncing Ball", 640, 480)
x = 100
y = 100
vx = 5
vy = 4

while window_is_open(win):
    ev = window_poll_events(win)
    if ev != null and ev.get("type") == "quit":
        break
    
    x = x + vx
    y = y + vy
    if x <= 20 or x >= 620:
        vx = -vx
    if y <= 20 or y >= 460:
        vy = -vy
        
    window_clear(win, 18, 18, 24)
    window_draw_circle(win, x, y, 20, 0, 230, 180, true)
    window_present(win)
    time_sleep(0.016)
