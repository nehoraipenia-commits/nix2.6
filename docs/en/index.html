Nix Programming Language 2.6

An elegant, high-performance programming language completely rewritten in native C++ with an AOT compiler and an integrated Qt6 GUI engine.

Key Highlights

⚡ Native C++ Speed

Optimized C++ tree-walk interpreter (~45x faster than Python) and AOT native compiler (~320x faster) producing standalone machine binaries.

🎨 Integrated Qt6 GUI Library

Built-in libnix_qt library for creating desktop applications with buttons, textboxes, progress bars, and real-time 2D canvas.

📦 100% Native Codebase

Legacy Python files have been entirely replaced by a clean, self-contained C++ architecture.

✨ Intuitive & Expressive Syntax

Combines ease of use and structure: fct, class, out(), cin(), for i * 10.

Quick Start

Create a file named hello.nx :

# Simple Nix program
using <math>

fct greet(name) {
    out("Hello", name, "!")
}

greet("Nix Developer")
out("Square root of 144:", math_sqrt(144))

for i * 3 {
    out("Iteration:", i)
}

Run it immediately with the C++ interpreter:

./nix run hello.nx

Or compile it into a lightning-fast native binary:

./nix build hello.nx -o hello_bin -O3
./hello_bin
