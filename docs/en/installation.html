Installation & Building Nix

Nix is built with C++17 and the Qt6 framework. It has no external Python dependencies.

Prerequisites

  • C++ Compiler: Apple Clang (macOS) or GCC (Linux) with C++17 support.
  • Qt6: QtWidgets, QtGui, QtCore frameworks (installable via brew install qt on macOS or apt install qt6-base-dev on Linux).
  • Make: GNU Make for building.

Compiling the Nix Engine

Run the Makefile in the project root directory:

make

This automatically produces:

  1. The Qt6 GUI library: lib/libnix_qt.a (static) and lib/libnix_qt.dylib (dynamic).
  2. The primary ./nix CLI binary compiled with -O3 optimizations.

Cleaning Build Artifacts

make clean

Nix CLI Reference

Command Description
./nix run script.nx [args...] Runs the script using the high-performance C++ interpreter.
./nix build script.nx -o binary Compiles the script to a standalone native executable.
./nix build script.nx -O3 Compiles with maximum machine optimization level (-O3).
./nix build script.nx --emit-cpp Outputs and keeps the intermediate generated C++ source file.
