Installation & Compilation de Nix

Le projet Nix est développé en C++17 avec la bibliothèque Qt6. Il ne nécessite plus aucun interpréteur Python.

Prérequis Système

  • Compilateur C++ : Clang (macOS) ou GCC (Linux) supportant la norme C++17.
  • Qt6 : Framework QtWidgets, QtGui, QtCore (installable via brew install qt sous macOS ou apt install qt6-base-dev sous Linux).
  • Make : Pour orchestrer la compilation.

Compiler le Moteur Nix

Rendez-vous à la racine du projet et lancez simplement :

make

Cette commande effectue automatiquement :

  1. La compilation de la bibliothèque graphique Qt6 C++ : lib/libnix_qt.a et lib/libnix_qt.dylib.
  2. La compilation du binaire CLI principal ./nix avec toutes les optimisations -O3.

Nettoyer les fichiers de build

make clean

Commandes CLI du binaire Nix

Commande Description
./nix run script.nx [args...] Exécute le script Nix avec l'interpréteur C++ optimisé.
./nix build script.nx -o binaire Compile le script en binaire natif autonome avec optimisations.
./nix build script.nx -O3 Compile avec le niveau maximal d'optimisation machine (-O3).
./nix build script.nx --emit-cpp Génère et conserve le code source C++ intermédiaire.
