Le Langage Nix 2.6

Un langage de programmation élégant, dynamique et moderne, réécrit à 100% en C++ natif avec son propre compilateur AOT et sa bibliothèque graphique Qt6 intégrée.

Points Forts de Nix

⚡ Performance Native C++

Interpréteur C++ optimisé (~45x plus rapide que Python) et compilateur AOT C++ (~320x plus rapide) produisant des binaires machine autonomes.

🎨 Interface Graphique Qt6

Bibliothèque libnix_qt native en C++ Qt6 pour créer des fenêtres, boutons, inputs, sliders, et toiles de dessin 2D temps réel.

📦 Zéro Dépendance Superflue

Tout le code Python a été éradiqué au profit d'un binaire C++ unique et de headers C++ modulaires.

✨ Syntaxe Intuitive

Un subtil mélange de simplicité et de clarté inspiré du C++ et de Python : fct, class, out(), cin(), for i * 10.

Exemple Rapide

Créez un fichier hello.nx :

# Exemple simple en Nix
using <math>

fct saluer(nom) {
    out("Bonjour", nom, "!")
}

saluer("Nix Developer")
out("Racine de 144 :", math_sqrt(144))

for i * 3 {
    out("Boucle numéro :", i)
}

Exécutez-le instantanément avec l'interpréteur :

./nix run hello.nx

Ou compilez-le en binaire natif exécutable ultra-rapide :

./nix build hello.nx -o hello_bin -O3
./hello_bin
