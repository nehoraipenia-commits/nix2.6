Module <sys>

Permet d'interagir avec le système de fichiers, l'environnement d'exploitation et les arguments en ligne de commande.

using <sys>

Fonctions Fichiers & Disque

Fonction Description
file_write(path, contenu) Écrit une chaîne de caractères dans un fichier (écrase si existant). Retourne true.
file_read(path) Lit et retourne l'intégralité du contenu d'un fichier texte sous forme de chaîne.
file_exists(path) Vérifie si un fichier ou un dossier existe. Retourne un booléen.
file_delete(path) Supprime un fichier sur le disque.

Fonctions Système & Processus

Fonction Description
sys_args() Retourne la liste des arguments passés en ligne de commande au programme.
sys_execute(commande) Exécute une commande shell système et retourne un dictionnaire contenant stdout, stderr et code.
os_name() Retourne le nom du système d'exploitation hôte (ex: "posix" ou "nt").
os_listdir([path]) Retourne la liste des noms de fichiers et répertoires présents dans le chemin spécifié (par défaut ".").

Exemple

using <sys>

# Écriture puis lecture
file_write("demo.txt", "Contenu de test Nix C++")

if file_exists("demo.txt") {
    texte = file_read("demo.txt")
    out("Lu :", texte)
    file_delete("demo.txt")
}

# Commande système
res = sys_execute("echo 'Hello Terminal'")
out("Sortie shell :", res["stdout"])
