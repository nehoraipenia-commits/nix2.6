Module <math>

Le module mathématique natif fournit des fonctions de calcul standard, de trigonométrie et de haute précision.

using <math>

Constantes

Constante Description
pi La constante Pi (3.141592653589793).
e La constante d'Euler (2.718281828459045).
pi_str Pi avec 100 décimales exactes sous forme de chaîne.

Fonctions Disponibles

Fonction Description Exemple
math_abs(x) Valeur absolue d'un nombre. math_abs(-42) -> 42
math_sqrt(x) Racine carrée (x >= 0). math_sqrt(25) -> 5.0
math_pow(base, exp) Puissance x^y. math_pow(2, 8) -> 256.0
math_ceil(x) Arrondi à l'entier supérieur. math_ceil(4.2) -> 5
math_floor(x) Arrondi à l'entier inférieur. math_floor(4.9) -> 4
math_sin(rad) Sinus en radians. math_sin(pi / 2) -> 1.0
math_cos(rad) Cosinus en radians. math_cos(0) -> 1.0
math_tan(rad) Tangente en radians. math_tan(0) -> 0.0
math_log(x, [base]) Logarithme naturel ou à base personnalisée. math_log(e) -> 1.0
math_factorial(n) Factorielle d'un entier positif n!. math_factorial(5) -> 120
hp_mul(a, b) Multiplication haute précision. hp_mul(3.5, 2.0) -> 7.0
hp_div(a, b) Division haute précision. hp_div(10, 3) -> 3.3333333333...
