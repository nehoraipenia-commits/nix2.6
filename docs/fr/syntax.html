Syntaxe Complète du Langage Nix

La syntaxe de Nix combine la lisibilité des langages dynamiques avec la rigueur des structures par accolades { ... }.

1. Variables & Types de Données

Le typage est dynamique avec inférence automatique :

# Nombres entiers et décimaux
age = 25
taux = 3.14159

# Booléens (en minuscules : true / false)
actif = true
bloque = false

# Chaînes de caractères
message = "Bonjour le monde"

# Vecteurs (tableaux ordonnés)
nombres = [10, 20, 30]
nombres.append(40)
premier = nombres[0]

# Dictionnaires (clé -> valeur)
utilisateur = {
    "nom": "Alice",
    "score": 100
}
utilisateur["score"] = 150

2. Entrées & Sorties : out() et cin()

# Affichage avec out(...)
out("Bonjour", "Nix", 2026)

# Lecture console avec cin(...)
nom = cin("Quel est votre nom ? ")
out("Enchanté", nom)

3. Conditions : if / else

score = 85

if score >= 90 {
    out("Excellent !")
} else if score >= 70 {
    out("Bien joué !")
} else {
    out("Courage pour la suite.")
}

4. Boucles : while et for

Nix propose une syntaxe de boucle for expressive avec l'opérateur * pour itérer de 0 à N-1 :

# Boucle for : 'for variable * limite'
for i * 5 {
    out("Itération :", i)
}

# Boucle while classique
compteur = 0
while compteur < 3 {
    out("Compte :", compteur)
    compteur = compteur + 1
}

5. Fonctions : fct

Les fonctions sont déclarées avec le mot-clé fct :

fct additionner(a, b) {
    return a + b
}

resultat = additionner(12, 30)
out("Résultat :", resultat) # 42

6. Classes & Objets : class

Nix supporte l'orientation objet avec des méthodes et propriétés internes :

class Guerrier {
    nom = "Arthur"
    points_de_vie = 100

    fct attaquer(degats) {
        points_de_vie = points_de_vie - degats
        out(nom, "a maintenant", points_de_vie, "PV")
    }
}

g = Guerrier()
out("Nom du guerrier :", g.nom)
g.attaquer(25)

7. Importation de Modules : using <...>

using <math>
using <time>
using <qt>
