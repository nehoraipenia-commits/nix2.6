Module <time>

Permet de mesurer des performances, d'ajouter des temporisations ou de formater l'heure locale.

using <time>

Fonctions

Fonction Description
time_now() Retourne l'horodatage système actuel (Epoch time en secondes sous forme de float haute précision).
time_sleep(secondes) Met en pause l'exécution du programme pendant secondes (accepte les valeurs décimales, ex: 0.5).
time_format([timestamp], [format]) Formate un timestamp en chaîne de caractères selon le modèle spécifié (par défaut "%Y-%m-%d %H:%M:%S").

Exemple de Mesure de Performance

using <time>

debut = time_now()

# Simulation d'un traitement
time_sleep(0.2)

duree = time_now() - debut
out("Traitement termine en :", duree, "secondes")

date_actuelle = time_format()
out("Date et heure courantes :", date_actuelle)
