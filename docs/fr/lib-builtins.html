Fonctions Intégrées & Méthodes d'Objets

Nix dispose de méthodes orientées objet sur les chaînes, listes et dictionnaires, ainsi que du module <builtins>.

Méthodes sur les Chaînes (Strings)

Méthode Description
s.upper() / s.lower() Convertit en majuscules ou minuscules.
s.strip() Retire les espaces en début et fin de chaîne.
s.split([sep]) Découpe la chaîne en liste selon le séparateur.
s.replace(old, new) Remplace les occurrences de sous-chaînes.
s.startswith(p) / s.endswith(p) Vérifie le préfixe ou suffixe.
s.find(sub) Retourne l'index de la sous-chaîne (-1 si introuvable).
s.isdigit() / s.isalpha() Tests sur la nature des caractères.

Méthodes sur les Vecteurs (Listes)

Méthode Description
v.append(element) Ajoute un élément à la fin du vecteur.
v.pop([index]) Retire et retourne l'élément à l'index (dernier par défaut).
v.insert(index, element) Insère un élément à la position spécifiée.
v.reverse() Inverse l'ordre des éléments en place.
v.sort([reverse]) Trie le vecteur par ordre croissant (ou décroissant si true).
v.clear() Vide le vecteur.

Méthodes sur les Dictionnaires

Méthode Description
d.keys() / d.values() Retourne la liste des clés ou des valeurs.
d.get(cle, [defaut]) Accède à une valeur sans lever d'erreur si absente.
d.pop(cle) Retire et retourne la valeur associée à la clé.
d.clear() Supprime toutes les entrées.

Module <builtins>

using <builtins>

out("Longueur :", len([1, 2, 3]))
out("Maximum :", max(10, 42, 5))
out("Somme :", sum([10, 20, 30]))
out("Range :", range(0, 5))
