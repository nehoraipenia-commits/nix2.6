Module Graphique Qt6 <qt> (libnix_qt)

La bibliothèque libnix_qt en C++ fournit un binding direct avec Qt6 pour créer des interfaces graphiques riches, stylées en CSS/QSS et entièrement interactives.

using <qt>

Gestion de Fenêtre & Boucle Automatique

Lorsque vous créez une fenêtre avec qt_window, elle s'affiche immédiatement. À la fin de votre script Nix, la boucle d'événements Qt6 se lance automatiquement : votre fenêtre reste ouverte sans que vous n'ayez besoin d'écrire de boucle while true ni d'appeler qt_run !

Création de Widgets

Fonction Description
qt_window(titre, largeur, hauteur) Crée et affiche une fenêtre principale Qt6.
qt_label(parent, texte) Crée une étiquette de texte (QLabel).
qt_button(parent, texte, [callback]) Crée un bouton poussoir (QPushButton) avec fonction de clic optionnelle.
qt_input(parent, [placeholder]) Crée un champ de saisie texte monoligne (QLineEdit).
qt_textarea(parent, [texte]) Crée une zone de texte multiligne (QTextEdit).
qt_checkbox(parent, texte, [coche]) Crée une case à cocher (QCheckBox).
qt_slider(parent, min, max, valeur) Crée un curseur coulissant horizontal (QSlider).
qt_progressbar(parent, min, max, val) Crée une barre de progression (QProgressBar).
qt_combobox(parent, [items]) Crée une liste déroulante (QComboBox).
qt_listwidget(parent, [items]) Crée une liste à sélection (QListWidget).

Conteneurs & Dispositions (Layouts)

  • qt_vbox(parent) : Conteneur vertical.
  • qt_hbox(parent) : Conteneur horizontal.
  • qt_frame(parent) : Cadre bordé décoratif.
  • qt_groupbox(parent, titre) : Groupe de widgets avec titre encadré.

Événements & Propriétés

Fonction Description
qt_set_text(widget, texte) / qt_get_text(widget) Définit ou lit le texte d'un widget (bouton, label, input, textarea).
qt_set_value(widget, val) / qt_get_value(widget) Définit ou lit la valeur numérique (slider, progressbar).
qt_is_checked(cb) / qt_set_checked(cb, bool) Vérifie ou modifie l'état d'une case à cocher.
qt_set_style(widget, qss) Applique une feuille de style CSS/QSS native.
qt_on_click(btn, callback_fct) Associe une fonction Nix déclenchée au clic du bouton.
qt_on_change(widget, callback_fct) Déclenché lors de la modification de valeur (slider, input, etc.).
qt_timer(ms, callback_fct, [repeat]) Déclenche une fonction Nix toutes les X millisecondes.

Boîtes de Dialogue

  • qt_msgbox(titre, message) : Boîte d'information.
  • qt_confirm(titre, question) : Boîte de confirmation Oui/Non (retourne bool).
  • qt_file_dialog([titre], [filtre]) : Sélecteur de fichier natif.
  • qt_color_dialog([titre]) : Sélecteur de couleur graphique.

Exemple Complet d'Application

using <qt>

win = qt_window("Nix Qt6 Démo", 400, 300)
qt_set_style(win, "QWidget { background: #181825; color: white; font-size: 14px; } QPushButton { background: #89b4fa; color: #111; padding: 8px; border-radius: 4px; font-weight: bold; }")

lbl = qt_label(win, "Entrez votre prénom ci-dessous :")
inp = qt_input(win, "Prénom...")

fct on_click() {
    nom = qt_get_text(inp)
    qt_set_text(lbl, "Bonjour " + nom + " !")
}

btn = qt_button(win, "Envoyer", on_click)
