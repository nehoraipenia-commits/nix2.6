Module Canvas 2D <window>

Le module <window> (également compatible sous l'alias <mac_window>) fournit un environnement de rendu graphique 2D temps réel propulsé par le double-buffering matériel de Qt6.

using <window>

Fonctions de la Toile (Canvas)

Fonction Description
window_open(titre, w, h) Ouvre une fenêtre Canvas de largeur w et hauteur h. Retourne l'identifiant de la fenêtre.
window_is_open(win) Retourne true si la fenêtre est toujours active, false si l'utilisateur l'a fermée.
window_poll_events(win) Dépile le prochain événement (clavier, souris) sous forme de dictionnaire {"type", "key", "x", "y"}.
window_clear(win, r, g, b) Efface l'écran avec la couleur RVB spécifiée (0 à 255).
window_draw_rect(win, x, y, w, h, r, g, b, [rempli]) Dessine ou remplit un rectangle.
window_draw_circle(win, cx, cy, rayon, r, g, b, [rempli]) Dessine ou remplit un cercle avec antialiasing.
window_draw_line(win, x1, y1, x2, y2, r, g, b, [epaisseur]) Trace un segment de droite.
window_draw_text(win, texte, x, y, r, g, b, [taille]) Affiche du texte sur le canvas avec police nette.
window_present(win) Met à jour l'affichage à l'écran (swap de buffer).
window_close(win) Ferme manuellement la fenêtre.

Exemple de Dessin Fixe (Sans boucle while)

using <window>

win = window_open("Mon Dessin Nix", 500, 400)

window_clear(win, 25, 25, 35)
window_draw_rect(win, 50, 50, 150, 100, 255, 100, 120, true)
window_draw_circle(win, 350, 200, 50, 100, 200, 255, true)
window_draw_text(win, "Toile 2D Nix C++", 160, 20, 255, 255, 255, 18)
window_present(win)

# La fenêtre reste automatiquement ouverte à l'écran !
