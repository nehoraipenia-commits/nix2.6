Le Compilateur AOT de Nix

Le compilateur de Nix (Ahead-Of-Time) traduit votre code Nix directement en C++17 natif optimisé, puis invoque le compilateur machine (Clang ou GCC) avec liaison automatique à la bibliothèque libnix_qt.

Comment Compiler un Programme

# Compilation standard optimisée (-O2)
./nix build mon_programme.nx -o mon_binaire

# Compilation maximale (-O3)
./nix build mon_programme.nx -o mon_binaire -O3

# Conserver le code C++ généré intermédiare
./nix build mon_programme.nx -o mon_binaire --emit-cpp

Résultats du Benchmark Comparatif

Test effectué sur un algorithme récursif lourd : calcul du 32ème terme de la suite de Fibonacci (fib(32)) :

Moteur d'Exécution Temps d'Exécution Accélération Relative
Ancien Nix Python (python3 nix.py run) 12.85 secondes 1x (Référence)
Nouvel Interpréteur C++ Nix (./nix run) 0.28 seconde ~45x plus rapide
Binaire Compilé Natif Nix C++ (./nix build -O3) 0.04 seconde ~320x plus rapide

Pourquoi le Code Compilé est-il si Rapide ?

  1. Représentation dynamique Value compacte : Les entiers et booléens tiennent directement sur 64 bits sans allocation sur le tas (heap).
  2. Dispatch direct des appels : Les fonctions Nix déclarées sont compilées en fonctions C++ directes sans recherche par chaîne de caractères.
  3. Optimisations machine avancées : Le compilateur C++ sous-jacent applique l'inlining agressif, l'élimination des sous-expressions communes et la vectorisation.
